# Política de privacidade — Kleytin TV

Site estático mínimo para publicar somente a política de privacidade do Kleytin TV no GitHub Pages. Não contém o aplicativo nem credenciais/listas de IPTV.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `kleytin-tv-privacy` na sua conta do GitHub.
2. Envie o conteúdo desta pasta para a raiz do repositório. A página está em `docs/index.html`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/docs`, e salve.
4. Aguarde o GitHub mostrar a URL HTTPS publicada na mesma seção. O endereço costuma seguir `https://SEU-USUARIO.github.io/kleytin-tv-privacy/`.
5. Abra o link em uma janela anônima para confirmar que carrega sem login e que o e-mail de suporte está correto.
6. Use a URL final no Seller Lounge e atualize o rascunho de cadastro do app.

Não publique o repositório até revisar o nome de usuário/URL e confirmar que está confortável em deixar a política e o e-mail de suporte publicamente acessíveis.
